🧭 Setup Guide

QuickPrint epdi setup pannuradhu

⏱️ 5 nimisham-la start aagidum · 🙋 Technical knowledge vendaam. Step-by-step follow pannunga.

Oru line-la: Demo-ku register pannunga → Owner approve pannuvaar → Shop Login pannunga → Printer & rates set pannunga → QR standee print pannunga → Test print pannunga. Avlo thaan.
Step 1–8 · 🖨️ Print setup
1

📝 Free demo-ku register pannunga

1 Week Free Demo form-la unga name, WhatsApp number, shop name, address, email, username, password kudunga. Username, password-a gnabagam vainga, login-ku adhu thaan.

2

✅ Owner approval-ku wait pannunga

Unga request QuickPrint owner-ku pogum. Approve pannina udane unga WhatsApp-ku message varum. Approve aagura varaikkum login aagaadhu, "waiting for approval" nu kaattum.

3

🔑 Shop Login pannunga

Shop PC-la browser (Chrome / Edge) open pannunga. /admin page-ku poi, register pannina username & password-la login pannunga.

4

🖥️ Admin page-a shop PC-la open-a vainga

Customer orders indha page-ku thaan varum, athanaala print aagura neram indha page open-a irukkanum. Browser address bar-la Install option kaattina, adhai click pannina desktop app maadhiri open aagum.

5

🖨️ Printer set pannunga

Shop PC-la unga printer Windows-la sariyaa install aagi irukkanum. Admin page-la B&W-kum Color-kum edhu printer nu select panni Save pannunga. Oru printer mattum irundha rendu idathulayum adhaiye select pannunga.

6

⚙️ Shop details & rates

Shop settings-la shop name, address, UPI ID, B&W / Color rate (per page) set pannunga. Customer-ku idhu thaan price-a kaattum. Auto print toggle on-la irukkanum, appo thaan paid orders thaanaave print aagum.

7

🔲 Counter QR standee print pannunga

Admin dashboard-la irukkura QR Standee page open panni print edunga. Counter-la customers-ku theriyura idathula otti vainga.

8

🎉 Test print pannunga

Unga phone-la andha QR-a scan pannunga. Oru PDF / photo upload pannunga, pay pannunga (illa counter cash select pannunga). Print nikkina setup mudinjadhu!

Optional · 💳 Payment
💳

UPI payment

Shop settings-la unga UPI ID sariyaa podunga. Customer pay panna paisa direct unga account-ku pogum, QuickPrint beech-la edukkaadhu. Online payment venaam, counter-la cash mattum podhum na UPI part skip pannalaam.

Help

Adikkadi problems

Login aagala, "waiting for approval" nu varudhu

Owner innum approve pannala. WhatsApp-la ungal request pathi message anuppunga, seekkiram approve pannuvaanga.

Login aagala, "License expired" nu varudhu

Demo (1 week) mudinjirukkalaam. Plan renew pannanum. WhatsApp-la contact pannunga, renew panna udane login aagum.

Customer pay pannaanga, aana print aagala

Shop PC-la admin page open-a irukkanu paarunga. Internet connected-a irukkanu paarunga. Settings-la Auto print on-la irukkanum. Printer Windows-la sariyaa irukkanum, test page print pannipaarunga.

Printer select panna mudiyala

Printer PC-la install aagi Windows-la default-a irukkanum. Admin page-a refresh panni thirumba paarunga.

Customer file server-la irukkuma?

Print mudinjadhum file server-la irundhu delete aagidum. Customer ethaavadhu cancel panninaalum adhe, file store pannaadhu.

Internet pona enna aagum?

Jobs queue-la irukkum. Internet vandhadhum print aagum.

Setup-la atkikitteengala?

Edha step-la prechana nu sollunga. Naanga help pannuvom.
